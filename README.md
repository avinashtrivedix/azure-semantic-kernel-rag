# Enterprise RAG Agent: Azure & Semantic Kernel

## Overview
This repository contains an end-to-end Retrieval-Augmented Generation (RAG) system built to enterprise standards. It leverages Microsoft's Semantic Kernel to orchestrate LLM workflows, deployed securely via Azure AI Studio.

This project was built to demonstrate proficiency in:
*   **Semantic Kernel & Python:** Orchestrating AI agents and native plugins.
*   **Azure AI Services:** Secure model provisioning and deployment.
*   **Data Privacy:** Implementing pre-processing guardrails to scrub PII before LLM execution.
*   **Full-Stack Integration:** Wrapping AI logic in REST APIs (FastAPI) and connecting to a React JS frontend.

## Architecture
1. **Backend:** Python, Semantic Kernel, FastAPI
2. **Frontend:** React JS
3. **Infrastructure:** Azure OpenAI, Vector Database
